Six Principles · 六个原则
想清楚这六件事，后面全部顺了

在讲任何技巧之前，先把底层认知想清楚。认知对了，状态自然稳。

01
原则 · 01 投入产出
算清楚投入产出比
Return on Investment
这两天学习，能多考的分数约 0.0%。两天比上三年，数学上算不明白。你现在唯一值得做的事，是调状态——不是补漏洞。再牛逼也就多考十分，而且还是撞大运。
投入产出比 · 三年 vs 两天 · 调状态优先
02
原则 · 02 概率
分数是概率云，不是命运判决
The Probability Cloud
你是550的水平，极限上下波动±20分。高考不会突然变形。树不长到天上，也不扎到地心。飞镖大概率落在最大块的部分——叫正态分布。
正态分布 · ±20分 · 概率云
03
原则 · 03 生理
适度紧张是好事，别追求完全平静
Optimal Arousal
肾上腺素和去甲肾上腺素让大脑血流更快、含氧量更高。完全不紧张是麻木状态。明天早上感到一点紧张，说明你活着，而且准备好了。
肾上腺素 · 战斗状态 · 适度紧张
04
原则 · 04 去魅
高考的价值，只剩20年前的十分之一
The Real Price Tag
经济下行、就业收缩、AI替代——高考已经不是改变命运的唯一入口。20年前算1000分，今天可能连150都没有。把高考当神，你就是神的仆人。
高考去魅 · 经济数据 · 工具而非神明
05
原则 · 05 代价
失败的代价，极其有限
The Real Cost of Failure
一本 vs 二本，平均月薪差300块，而且要四年后才兑现。你爸妈最多冷战一个月——虎毒不食子。你所有的恐惧，不过是在害怕一顿饭钱。
月薪差300 · 四年后兑现 · 虎毒不食子

单标准、确定反馈的旧游戏结束了。开放的、市场定价的、靠作品说话的沙盒游戏，刚刚开机。高考之后你还要活七八十年，这才是第一关。

关于失眠：最极端的情况也没什么大不了

脑神经科学证明：没睡好的情况下，神经反而更活跃，更有利于发散思维——语文考的正是发散思维。你唯一需要担心的是：中午能不能睡着？头天晚上没睡，中午一定能睡着，数学状态照样能恢复。

Exam Prep · 考前两天
做什么，不做什么

这两天的唯一目标：以最稳定的状态进入考场。不要逆袭，不要弥补，保住生物钟，调好状态。

→

翻一遍旧的错题，过一遍英语作文模板

→

9点到11点、3点到5点各做一套旧卷——不对答案

→

散步、轻运动，让自己稍微疲劳，保住生物钟

→

平时几点睡就几点睡，不要刻意调整

→

下午去踩点：走两遍路线，找到厕所，看好桌椅

→

Full Rehearsal · 6月7日全流程
逐节点预演，陌生感清零

把每一个「不确定」提前变成「已知」。今天在这里经历一遍，明天在考场就不是第一次了。

NODE · 01
前一天下午
踩点

用身体标记领地

  • 走两遍路线，熟悉每一个转弯和路口
  • 找到教室，感受桌椅，看好空调位置
  • 去一趟厕所——在这栋楼沾染了你的味道，这是你的窝了
  • 如果有老师，打个招呼；把所有横幅都笑一遍，明天就不新鲜了
NODE · 02
当天早晨
出发前

爸妈会反常，你要正常

  • 他们一改平日凶猛，变得异常温柔——这是回光返照，不要被感动得焦虑
  • 正常吃早饭；七点半出发，留足时间
  • 路上的横幅、彩旗——昨天踩点都见过了，没什么大不了
NODE · 03
进场
8:30–8:55

监考老师是盟友，不是法官

  • 他心里只想打麻将回家，并没有比你更严肃
  • 安检、刷脸、对准考证——这套流程你考了一百多次了
  • 想上厕所立刻举手，老师一定同意，不要死扛
NODE · 04
语文考试
9:00–11:30

你一定能写完作文

  • 诗歌默写全错最多丢4分，就一道选择题——接受它，往下做
  • 注意力不要破碎：连续专注效率是碎片注意力的3-5倍
  • 树林亲测：只剩20分钟、一字未写，最终850字全部写完，题也答完了
NODE · 05
语文考完
中午

关掉网络，回家睡觉

  • 不要和任何人讨论答案——讨论只会搞心态，而且改不了任何结果
  • 不要看B站老师们发的卷子解析——那是给高一高二拍的流量，不是给你的
  • 中午必须休息，哪怕睡不着也要闭眼躺着
NODE · 06
数学考试
下午

做好预期：一定考砸，这才是正常的节奏

  • 你数学考完有哪一次是笑嘻嘻的？没有。万念俱灰才是你最熟悉的节奏
  • 前三道大题可能有1-2道卡住——这是出题人的设计，不是针对你
  • 遇到不会的：默念「我拒绝在这里得分」，跳过，做下一题
Subject Guide · 科目攻略
语文 & 数学，逐科脱敏
— 语文 —

诗歌默写：最多丢4分，就一道选择题

哪怕六句一句都不会，也不过就是数学里的一道选择题。接受它，继续做下一题。你要随机丢200分，在这里丢有什么不好？

注意力不要破碎

不要做一道题就去看作文题目，做一道题又去看默写。连续深度专注的效率是破碎注意力的3-5倍。一段做完再换。

作文：你不会写不完，你也不会跑题

树林亲测：仅剩20分钟、一字未写，最终850字全部写完，题也答完。巧妇难为无米之炊，但你是高考生。

— 数学 —

前几道也可能卡壳，这是正常的

出题人在小黑屋里想了三四个月专门挖坑。前几道选择题发愣是正常的——其他所有人也一样，你的相对位置没有变。

「我拒绝在这里得分」

遇到不会做的题，不要死磕，不要焦虑。默念：我拒绝在这里得分，这是为了让整体均值回归。跳过，做下一题。这是主体性，不是认输。

大题考知识点的交叉处

高考大题一定考知识点的交汇处——正弦+余弦+面积公式+诱导公式。看到题目先想：它同时调用了哪几个知识点？往后多倒一步。

你所有错的题目，都是命题人让你错的题目。
你所有对的题目，都是他们让你能得到的分。
每个人都要固定地踩几个坑，这才是保证高考公平公正公开的核心。
—— 树林 · 2026年6月5日直播
